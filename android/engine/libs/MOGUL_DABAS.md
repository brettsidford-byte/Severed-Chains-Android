# Mogul Dabas Android artifact

`mogul-dabas-0.0.1-java17.jar` is a Java 17-compatible build of
[`Legend-of-Dragoon-Modding/Dig-Dabas`](https://github.com/Legend-of-Dragoon-Modding/Dig-Dabas)
version 0.0.1. Both projects use the GNU Affero General Public License v3.0.

The GitHub `main` source archive used has SHA-256
`CBCC2EFC47298254885DC596A65432B838EDAFFB19C23CF1D3E25FAA6F3D9DDE`.
It was built without source modifications using Gradle 8.9, JDK 21, and
`--release 17`; its unused mod-loader build dependency was excluded because
the module source imports no mod-loader classes. The resulting jar has SHA-256
`F697DF9C0E0E3541A9A64AF9DD0AAE31E35E8E94AA29A4AA3C854C190647A9B5`.
